# Valentina Cambiaso · Portfolio

Personal site with a terminal aesthetic, available in English and Spanish.

🔗 [Live site](https://valentina-cambiaso.vercel.app/)

## Stack

- Vanilla HTML / CSS / JavaScript (no frameworks, no build step)
- EN/ES translations centralized in `i18n.js`

## Structure

```
portfolio.html   page markup
styles.css       styles
script.js        language toggle, typing effect, scroll reveal
i18n.js          English and Spanish copy
```
